# Final Demo Guide

## 3분 시연 순서

1. `paderborn:K001:N09_M07_F10:01` healthy Measurement를 선택하고 Normal Report를 보여준다.
2. `paderborn:KA01:N09_M07_F10:01` damaged Measurement를 선택해 ML 이상탐지와 Agent Office route를 보여준다.
3. `bearing_v1` 근거와 citation을 확인하고 진단 후보, Inspection Plan, Recommended Action을 보여준다.
4. Controlled HITL 시나리오에서 추가 정보를 요청하고 같은 `run_id`로 재개되는 흐름을 보여준다.
5. Final Report에서 version trace, 근거, 한계, 사람의 의사결정 지원 범위를 강조한다.

실제 설비 자동제어가 아니라 센서 분석·근거검색·진단지원·점검계획을 제공하는 MVP임을 명시한다. Multimodal 이미지는 Paderborn vibration measurement와 동기화된 동일 설비 이미지가 아니다.
