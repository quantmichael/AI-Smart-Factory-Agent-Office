# User Test Protocol

## 목적

실제 사용자가 Measurement 선택부터 Final Report 확인까지 Agent Office 흐름을 이해하고 사용할 수 있는지 평가한다.

## 대상

최소 5명: 제조/설비 관심 사용자, 개발/AI 사용자, 일반 사용자를 섞는다. 개인정보 대신 `participant_id`만 기록한다.

## 과업

1. 설비 Measurement Sample 선택
2. Agent 진단 시작
3. Agent Office 진행 상태 확인
4. 이상 원인과 근거 확인
5. Inspection Plan 확인
6. HITL 요청에 응답하거나 추가 정보 확인
7. Final Report 확인

## 정량 질문

각 항목을 1~5점으로 평가한다.

- 진단 진행과정을 이해하기 쉬웠다.
- AI가 왜 이런 판단을 했는지 근거를 확인할 수 있었다.
- 다음 점검 행동을 이해할 수 있었다.
- Agent Office가 현재 작업상태 이해에 도움이 되었다.
- 전체 서비스를 다시 사용할 의향이 있다.

## 정성 질문

- 가장 이해하기 어려웠던 부분은?
- 가장 유용했던 기능은?
- 불필요하거나 복잡했던 기능은?
- 근거 제시는 충분했는가?
- 실제 현장에서 사용한다면 무엇이 더 필요한가?

## 기록 원칙

실제 응답만 `participant_results.csv`에 기록한다. 참가자가 없을 때는 결과를 추정하거나 합성하지 않는다.
